# Mobile Joe

Native tools for iOS and Android apps, built for indies and small teams.

Add feature voting, targeted in-app alerts and FAQs to your app. You curate the feature plans, your users vote. Native SDKs, customizable UI components, backend and dashboard included.

Get started with our [iOS SDK](https://github.com/MobileJoeDev/mobilejoe-ios) or [Android SDK](https://github.com/MobileJoeDev/mobilejoe-android).
