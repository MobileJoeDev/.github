# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues.

Report them privately via GitHub instead: open the affected repository, select **Security**, then **Report a vulnerability**. Use these forms for the [iOS SDK](https://github.com/MobileJoeDev/mobilejoe-ios/security/advisories/new) and the [Android SDK](https://github.com/MobileJoeDev/mobilejoe-android/security/advisories/new).

Include the affected version, steps to reproduce, and the potential impact. We'll confirm receipt and keep you updated while we investigate.

## Supported versions

Security fixes are released for the latest version of each SDK.
