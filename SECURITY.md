# Security Policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues.

Report them privately via GitHub instead: open the affected repository, select **Security**, then **Report a vulnerability**. For the iOS SDK, use [this form](https://github.com/MobileJoeDev/mobilejoe-ios/security/advisories/new).

Include the affected version, steps to reproduce, and the potential impact. We'll confirm receipt and follow up when we have a fix or need more details.

## Supported versions

Security fixes are released for the latest version of each SDK.
